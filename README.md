# Xiangcheng Yang

Personal academic homepage of Xiangcheng Yang, an incoming Ph.D. student at Nanjing University.

## Live Site

Visit the homepage at: [https://yangxc0414.github.io](https://yangxc0414.github.io)

## Overview

This repository contains the source of my personal homepage, built with [Jekyll](https://jekyllrb.com/) and based on the [AcadHomepage](https://github.com/RayeRen/acad-homepage.github.io) template. The site is served through GitHub Pages.

## Contents

- `_pages/about.md` — main content of the homepage (about, news, publications, honors, etc.)
- `_config.yml` — site configuration (title, author info, social links)
- `_data/navigation.yml` — navigation menu items
- `_includes/` and `_layouts/` — page structure and reusable components

## Development (Optional)

To build and preview locally:

1. Install [Ruby](https://www.ruby-lang.org/) and [Jekyll](https://jekyllrb.com/)
2. Run `bash run_server.sh` (or `bundle exec jekyll serve`)
3. Open http://127.0.0.1:4000 in your browser

Changes are published automatically via GitHub Pages when committed to the `main` branch.
